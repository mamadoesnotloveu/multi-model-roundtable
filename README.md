# 多模型圆桌讨论

让 Claude、GPT、DeepSeek 一起讨论同一个话题，经过辩论、起草、表决，最终产出共识方案。

**全程只在你本机运行**：不需要买域名、不需要租服务器，网页只在你自己的电脑上打开，别人访问不到。

## 工作流程

1. **辩论**（N 轮，默认 2 轮，最多 10 轮）：各模型轮流发言、互相点评反驳；
2. **起草**：起草人（默认 DeepSeek，可改）根据讨论起草一份方案草案；
3. **表决（盖章）**：每个模型对草案给出「同意 / 部分同意 / 不同意」的独立表态；
4. **修订定稿**：起草人综合各方表决，产出最终定稿，包含三部分：
   - 【最终方案】吸收各方意见后的最终方案；
   - 【各方盖章】每个模型的立场与理由；
   - 【保留分歧】仍无法调和的分歧及各方立场。

## 使用说明

网页分两个标签页：

- **💬 新讨论**：填话题（可选上传 Word / PPT / Excel 附件，文件会被提取成文字供三个模型一起讨论）→ 点「🚀 开始讨论」。想换话题时，点「🧹 清空话题」或直接改掉话题框里的文字再开始即可。
- **📂 历史讨论**：每次讨论完成后会**自动保存**，在这里下拉选择即可随时回看。

> 历史讨论保存在项目目录下的 `discussions/` 文件夹里，每个讨论一个 `.json` 文件，可以用任何文本编辑器打开，也可以整个文件夹备份走。

## 快速开始（一键）

双击项目里的 `start_roundtable.command` 即可（想在桌面放图标，可右键它 → 制作替身，把替身拖到桌面）：

- 首次运行会自动创建环境并安装依赖；
- 之后每次双击都会自动启动并打开浏览器。

> 首次运行前，请先按下面的方法填好 API Key。

## 配置 API Key（一次性）

1. 在项目目录里，把 `.env.example` 复制成 `.env`。
2. 用文本编辑器打开 `.env`，填入三把 Key：
   ```
   ANTHROPIC_API_KEY=sk-ant-xxxx
   OPENAI_API_KEY=sk-xxxx
   DEEPSEEK_API_KEY=sk-xxxx
   ```
3. 保存。Key 只存在你本机的 `.env` 文件里，不会经过浏览器或网络。

> 为什么不在网页里填 Key？因为网页服务（即使是本地的）理论上存在被浏览器跨站访问的风险，把 Key 放进本地 `.env` 文件最安全。

### 用中转服务（如 B.AI）访问 Claude

如果你的 Claude Key 来自 B.AI 等中转服务，还需要在 `.env` 里加一行接口地址：

```
ANTHROPIC_BASE_URL=https://api.b.ai
```

用官方 Anthropic 就删掉这行或留空。注意：中转服务的模型名可能和官方不同（例如 B.AI 实测支持 `claude-sonnet-5`、`claude-opus-4-8`、`claude-haiku-4-5`，但不支持 `claude-fable-5-1`），以中转平台实际提供的为准。

## 各平台 Key 与默认模型名

| 平台 | Key 环境变量 | 默认模型名 |
| --- | --- | --- |
| Claude | `ANTHROPIC_API_KEY` | `claude-sonnet-5` |
| OpenAI | `OPENAI_API_KEY` | `gpt-5.6-terra` |
| DeepSeek | `DEEPSEEK_API_KEY` | `deepseek-v4-pro` |

模型名可以在网页左侧「⚙️ 模型名」一栏随时修改（改动自动保存）；起草人可以在「🎙️ 起草人 / 主持人」一栏切换（默认 DeepSeek）。

## 手动启动（备用）

如果不想用一键脚本，也可以在终端运行：

```bash
# 进入项目目录后运行
./venv/bin/streamlit run app.py
```

## 使用建议

- 讨论轮数默认 2 轮（初步观点 + 互相反驳），想更深入可调到 3 轮。
- 一次完整讨论约调用「模型数 × 轮数 + 1（起草）+ 模型数（表决）+ 1（定稿）」次，费用几毛到几块钱人民币。
- 轮数越多，每轮要读的历史越长，10 轮时可能逼近模型上下文上限；遇到截断或报错可把轮数调低。
- 模型名会随时间更新，若某模型报“找不到模型”，去对应官网看最新名称，在网页侧边栏修改即可。
